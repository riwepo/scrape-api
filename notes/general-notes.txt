note port 3000 is in use
had to use port 3001

note there is a setting in docker networking
enable host networking that must be checked
then the container can be reached without specifying the host

to run a post from powershell use -
Invoke-WebRequest -Uri "http://localhost:3001/scrape" `
  -Method POST `
  -Headers @{ "Content-Type" = "application/json" } `
  -Body '{"url": "https://www.ted.com/talks/eric_schmidt_the_ai_revolution_is_underhyped/transcript", "selector": "button > div > i:first-of-type"}'

to build docker image
docker build -t scrape-api .

to run docker image
-p maps port from outside to inside
the first port is the host port
the second port is the port inside docker
docker run -p 3001:3001 scrape-api

to know what port on the host machine is mapped to docker
use command
docker ps
